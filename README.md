# -IAM-
Университеттің жеке басты сәйкестендіру және қолжетімділікті басқару жүйесі. Жүйе пайдаланушыларды тіркеуге, қауіпсіз кіруге, рөлдерді басқаруға және көпфакторлы аутентификацияны қолдануға арналған.
Негізгі функциялары
Пайдаланушыларды тіркеу және жүйеге кіру.
Құпиясөздерді BCrypt арқылы қауіпсіз сақтау.
Көпфакторлы аутентификацияны (MFA) қолдану.
JWT арқылы пайдаланушы сессияларын басқару.
Рөлдер бойынша қолжетімділікті басқару (RBAC).
Қате кіру әрекеттерін шектеу.
Әрекеттер журналын жүргізу.
Қолданылатын технологиялар
Java
Spring Boot
Spring Security
PostgreSQL
JUnit
Жобаның мақсаты
Университет жүйесіндегі пайдаланушылардың деректерін қорғау және олардың жүйедегі құқықтарын қауіпсіз басқару.
